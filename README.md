# Curso de Análisis de Algoritmos

Repositorio creado para almacenar los laboratorios, ejercicios y benchmarks desarrollados durante el semestre de la asignatura **Análisis de Algoritmos**.

## Estructura del repositorio

- **laboratorios/**: contiene los informes de los laboratorios evaluativos.
- **ejercicios-clase/**: contiene los ejercicios realizados durante las clases.
- **benchmarks/**: contiene scripts para medir tiempos de ejecución y realizar comparaciones de rendimiento.
- **lab1-fundamentos-complejidad-recurrencias/**: contiene el desarrollo del Laboratorio Evaluativo 01, incluyendo el informe, código fuente, experimentos y gráficas.

## Laboratorio Evaluativo 01

El laboratorio **Fundamentos, complejidad y recurrencias** aborda el análisis de algoritmos de ordenamiento mediante el caso de estudio de la plataforma Tamiza.

El desarrollo incluye:

- Análisis de corrección y eficiencia de algoritmos.
- Análisis de mejor caso, peor caso y caso promedio.
- Implementación de **Insertion Sort** y **Merge Sort**.
- Análisis de complejidad.
- Medición de tiempos de ejecución y comparaciones.
- Generación de gráficas para comparar el comportamiento de los algoritmos.

Los archivos correspondientes se encuentran en:

```text
lab1-fundamentos-complejidad-recurrencias/
```
