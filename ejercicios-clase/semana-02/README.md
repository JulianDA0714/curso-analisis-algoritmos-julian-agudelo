# Laboratorio 02 — Configuración del entorno de trabajo

El entorno virtual se creó en la raíz del repositorio con `python -m venv venv`.
En Git Bash se activó con `source venv/Scripts/activate`.
El entorno activo se verificó comprobando el prefijo `(venv)` en la terminal.
Las dependencias se instalaron dentro del entorno virtual con `pip install matplotlib`.
El archivo `requirements.txt` se generó con `pip freeze > requirements.txt`.
Para reproducir el entorno, se debe crear y activar un nuevo `venv`.
Luego se instalan las dependencias con `pip install -r requirements.txt`.
